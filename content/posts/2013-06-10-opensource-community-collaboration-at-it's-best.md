Today I had a great experience with contributing to an opensource project [redline](https://github.com/craigwblake/redline) (Redline is a pure Java library for manipulating RPM Package Manager packages). Actually it was last week and today I had this pleasure.

Last week I fixed some lines in code and pulled a [merge request](https://github.com/craigwblake/redline/pull/24). The same day, just 2 hours later, it was merged.

Today I asked for a release to benefit from these changes without publishing an separate inhouse version. I offered some additional refactorings to justify a release, however [Craig W. Blake](https://github.com/craigwblake) did not discussed or requested some more changes. An new [release](http://search.maven.org/#search%7Cga%7C1%7Ca%3A%22redline%22) is already online.

I really appreciate that kind of cooperation. That's why I love opensource and my company [Immobilienscout24](http://www.immobilienscout24.de) is sharing and contributing to the opensource world.

See our projects at [github.com/ImmobilienScout24](https://github.com/ImmobilienScout24). Feel free to use it, to contribute or just report bugs!
